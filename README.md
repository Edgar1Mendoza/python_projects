# Python Projects Exercises

A collection of Python exercises organized by topic. Each script is small, standalone, and demonstrates a specific programming concept.

## Topics Covered

| Section | Topics |
| [1_beginning](./1_beginning) | Printing, patterns, initials, and basic output |
| [2_variables](./2_variables) | Variables, arithmetic, formulas, and unit conversion |
| [3_if_else](./3_if_else) | Conditionals, comparisons, and branching |
| [4_loops](./4_loops) | `for` loops, `while` loops, iteration, and control flow |
| [5_lists](./5_lists) | Lists, list operations, filtering, and list comprehension |
| [6_functions](./6_functions) | Function definitions, parameters, return values, and scope |
| [7_classes](./7_classes) | Classes, objects, attributes, and object methods |
| [8_modules_libraries](./8_modules_libraries) | Modules, imports, `random`, `math`, and `datetime` |

## Requirements

- Python 3
- No third-party packages

The standard-library modules used include `random`, `math`, and `datetime`.

## Running an Exercise

From the project root, run a script with Python:

```bash
python3 1_beginning/01_hello_world.py
```

Run another section's exercise in the same way:

```bash
python3 8_modules_libraries/01_slot_machine.py
```

On systems where `python` refers to Python 3, you can replace `python3` with `python`.
